# Nový směr — public legal pages

Public Privacy Policy and Support pages for the iOS app **Nový směr** (`cz.novysmer.app`).

## Enable GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Source: **Deploy from a branch**
3. Branch: `main` / folder `/ (root)`
4. Save

After a minute, pages will be available at:

- Home: `https://jurajpavol-ui.github.io/novy-smer-legal/`
- Privacy Policy: `https://jurajpavol-ui.github.io/novy-smer-legal/privacy-policy.html`
- Support: `https://jurajpavol-ui.github.io/novy-smer-legal/support.html`

Use these HTTPS URLs in App Store Connect (Privacy Policy URL + Support URL).
